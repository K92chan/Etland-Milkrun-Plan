⚡ 코스 최적화

미지정 + 현재 배치된 일반 지점을 모두 수거하여 선택한 기준으로 재배분합니다.
최적화 알고리즘은 좌표 직선거리(Haversine)를 사용하며 API 호출 없이 즉시 실행됩니다.
적용 후 🔄 전체계산으로 실제 도로 거리·시간을 확인하세요.
⚠️ 기존 배치가 초기화되고 새로 배분됩니다.
🗺 거리 최소화
물류거점을 기준으로 각 지점의 방위각(각도)을 계산하여 지리적 섹터로 나눕니다. 각 호차 내 경유 순서는 최근접 이웃(NN) 알고리즘으로 최적화합니다.
알고리즘: 각도 스윕 + NN 순서 최적화
⚖️ 물동량 균등
물동량이 큰 지점부터 각 호차에 균등하게 배분합니다. 특정 차량만 과부하되는 현상을 방지하며, 각 호차의 합산 물동량이 최대한 같아집니다.
알고리즘: 물동량 내림차순 → 최소 힙 배분 + NN 순서
🚏 경유지 균등
각 호차의 정차 지점 수를 최대한 같게 배분합니다. 인근 지점을 인접 호차에 나눠 분산시키므로 운행 시간 편차도 줄어듭니다.
알고리즘: 거리순 정렬 → 라운드로빈 + NN 순서
